# 01. Multi Agent Lab: 연구 배경과 실험 경과

## 이 슬라이드가 필요한 이유

발표 초반에 시스템의 목적과 연구의 진행 단계를 알려주기 위한 슬라이드입니다. 청중이 “이미 우수성이 입증된 모델을 소개하는 발표”로 오해하지 않도록 범위를 설정합니다.

## 슬라이드 본문

### 어떤 연구인가

코드를 작성하는 AI 옆에 검토용 AI를 두고, 사람에게 확인해야 할 사항을 찾아 질문하게 하는 연구입니다.

### 무엇을 발표하는가

이 구조를 어떻게 구현했고 어떤 문제로 시험했는지 설명합니다. 이어서 현재 비교 방식의 한계와 다음 실험 계획을 제시합니다.

### 현재 연구 단계

실제로 작동하는 환경과 예비 실험 결과를 확보했습니다. 단일 AI보다 더 정확하거나 효율적인지는 아직 비교 검증이 필요합니다.

**핵심 메시지:** 핵심 질문: 여러 AI가 검토하는 방식은 같은 결과를 더 적은 비용으로 만들 수 있을까?

## 발표할 때 풀어서 설명하기

이 프로젝트는 새로운 언어모델을 학습한 연구가 아닙니다. 기존 AI 모델을 작업 담당과 검토 담당으로 나누고, 필요한 순간에 사람에게 질문하게 하는 실행 방식을 만들었습니다. 예를 들어 예약 프로그램을 만들 때 취소 마감이나 휴무일이 요구사항에 없다면 AI가 임의로 결정할 수 있습니다. 우리는 검토 담당 AI가 이런 빈칸을 찾아내고, 사람의 답을 받은 뒤 작업 담당 AI가 코드를 고치도록 연결했습니다. 오늘은 이 환경의 구현과 예비 실험, 그리고 앞으로 어떤 비교를 해야 연구적 의미가 있는지를 설명하겠습니다.

## 해석할 때 주의할 점

이 발표에서 “제안 구조”는 학습한 새 모델이 아니라 여러 모델 호출을 연결한 작업 방식입니다. 예비 실험은 본격 비교 전에 동작과 문제점을 확인하는 단계입니다.

## 다음 슬라이드 연결

먼저 코드가 실행된다는 것과 사용자가 원하는 프로그램을 만들었다는 것이 왜 다른지 보겠습니다.
