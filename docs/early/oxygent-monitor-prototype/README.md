# OxyGent 최소 감시 프로토타입

작업자 1개에 감시 역할 3개를 붙이는 **API 없는 모의 실행**입니다.
OxyGent에서는 `MAS`, `Workflow`, 요청·응답 형식만 사용합니다.
모든 판단과 수정은 Python 규칙으로 작성되어 있습니다. LLM 에이전트의 판단 능력이나 논문 성능을 입증하는 결과가 아닙니다.

```text
작업자: 예약 취소 정책 작성
  ├─ 요구사항 분석가: 문서에 없는 정책이면 질문
  ├─ 검증 엔지니어: 경계값·권한 등 기능 검사
  └─ 변경 영향 분석가: 답변 반영·취소 후 알림 검사
          ↓
  질문 → 인간 답변 → 작업자 재실행 → 재검증
  명세가 확실한 오류 → 자동 수정 → 재검증
```

별도 총괄 모델은 없습니다. 실행 순서와 재시도는 프로그램이 제어합니다.
세 감시 역할은 같은 작업 상태의 복사본을 받아 OxyGent의 `request.call()`로 병렬 호출됩니다.

## 실행

이 컴퓨터에는 프로젝트 전용 `.venv`가 준비되어 있습니다.
Finder에서 **실행.command**를 더블클릭하면 시간과 경계 포함 여부를 입력할 수 있습니다.
또는 이 폴더에서 다음을 실행하세요.

```sh
.venv/bin/python main.py
```

| 명령 | 확인할 흐름 |
|---|---|
| `.venv/bin/python main.py` | 명세 누락 → 직접 답변 → 반영 확인 |
| `.venv/bin/python main.py --demo` | 위 흐름에 예시 답변을 자동 입력 |
| `.venv/bin/python main.py --case documented` | 문서에 24시간·경계 포함이 있음 → 질문 없이 완료 |
| `.venv/bin/python main.py --case bug` | 의도적으로 잘못된 경계값 → 질문 없이 자동 수정 |

`--demo`는 실제 인간 평가가 아닙니다. 기본 입력은 정수 시간과 y/n 두 항목입니다.
취소 정책 외의 공통 요구사항은 **본인 예약만 취소 가능, 이미 취소된 예약은 재취소 불가,
취소된 예약에는 알림 없음**으로 고정했습니다.
`documented`의 문서 정책은 코드 안의 고정 입력입니다. 실제 파일 검색·문서 해석은 구현하지 않았습니다.

## 확인할 결과

`runs/`에 실행마다 JSON 기록을 저장합니다. 각 감시 역할의 판정, 근거, 실제 검사값,
사용자 답변, 정책 버전, 최종 구현 설정, OxyGent trace ID가 포함됩니다.
실제 동작은 `main.py`의 `can_cancel()`과 `should_notify()`가 담당합니다.

| 수치 | 의미 |
|---|---|
| 검증 통과 / 전체 | 최종 기능 검사 9개 + 정책 내용·버전 검사 2개 |
| 질문 횟수 | 시간·경계 포함 여부를 함께 묻는 질문 묶음 수 |
| 자동 수정 횟수 | 확정된 정책에 따라 다시 구현한 횟수 |
| 작업자 실행 횟수 | 답변·수정 전후를 포함한 실행 단계 수 |

현재 과제 3개는 제어 흐름 확인용입니다. 숨겨진 평가셋이나 독립 벤치마크가 아니며,
규칙이 검사 항목을 알고 있으므로 통과율을 모델 성능으로 보고하면 안 됩니다.
다른 작업자와의 병렬 프로젝트 실행, 장기 메모리, 중단 후 재개, 자유로운 코드 생성,
자연어 피드백 해석은 이번 최소 범위에 포함하지 않았습니다.
알림은 별도 에이전트가 아니라 같은 작업 안의 함수입니다.

## 다른 컴퓨터에서 설치

Python 3.12 기준으로 확인했습니다. 최초 패키지 설치만 인터넷이 필요하며 실행 시 API 키는 필요 없습니다.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py --demo
```

OxyGent 배포 패키지는 여러 라이브러리를 함께 설치합니다. 원본 저장소 전체를 복사하지 않았으며,
이 코드에서 쓰는 실행 구성요소는 `MAS`와 `Workflow` 두 가지입니다.
OxyGent의 모델 SDK 의존성은 설치되지만 실제 모델 인스턴스를 만들거나 호출하지 않습니다.

검증: `.venv/bin/python -m unittest discover -s tests -v`
네트워크 연결을 차단한 상태에서 실제 OxyGent 실행을 포함한 9개 테스트를 확인했습니다.
실행 시 OxyGent 내부 `LocalRedis`의 Pydantic 직렬화 경고가 표시될 수 있습니다.
이 버전의 상위 라이브러리 경고이며, 세 시나리오의 완료와 결과 저장을 확인했습니다.

구현 참고: [OxyGent 공식 저장소](https://github.com/jd-opensource/OxyGent),
[Workflow 구현](https://github.com/jd-opensource/OxyGent/blob/cd96268de5814dfb4e0444cfd687f97508cf996a/oxygent/oxy/flows/workflow.py).
배포 패키지 버전은 `oxygent==1.1.3`입니다.
