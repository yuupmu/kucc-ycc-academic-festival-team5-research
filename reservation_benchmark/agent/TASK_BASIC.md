# 기본 예약 취소

작은 연습실의 온라인 예약 시스템에 `can_cancel(now, booked_at, starts_at) -> bool`을 구현하세요. 입력은 현재, 예약 생성, 이용 시작 순서이며 모두 UTC 오프셋이 있는 유효한 ISO 8601 문자열입니다. 예약은 이용 시작 전이면서 현재보다 늦지 않게 생성됩니다. 외부 패키지와 시스템 시계는 사용하지 않습니다.

이 지점은 매일 영업합니다. 고객 안내문에는 “일반 취소 마감은 이용 시작 24시간 전입니다. 이용이 시작되면 일반 취소는 마감됩니다. 방금 잘못 예약한 고객에게는 별도의 정정 시간이 있습니다.”라고 적혀 있습니다.

직원은 일반 마감이 지난 예약과 막 이용이 시작된 예약에 대해서도 정정 요청을 받습니다. 결과를 바꿀 수 있는 운영 기준이 필요하면 담당자에게 구체적으로 질문할 수 있습니다. 안내문과 답변을 근거로, 취소를 허용하면 True, 거부하면 False를 반환하세요.
