# 중간 가채점 비공개 조건으로 다시 실행한 A·B·C·D

11월 25일의 188/240점은 모델이 공개 예시의 기대값과 실제 반환값을 받은 조건의 점수다. 프로그램이 그 결과로 D에게 제시할 후보와 복구 호출 여부도 정했다. 비공개 40문항의 정답을 숨겼더라도 중간 가채점 정보를 모델에 제공한 것이므로, 해당 수치와 단독 대비 19점 상승은 규정 준수 조건의 결과에서 제외한다. [이전 실행 기록과 정정](../qwen3-candidate-abcd-20261125/README.md)

정정 대상은 실행 표를 전달한 두 조정안이다. 그보다 앞선 ‘의견 요약 후 메인 수정’ 3회차 실험은 모델 호출을 모두 마친 뒤 채점했다. [원래 3회차 실험의 채점 시점](../qwen3-review-cycles-20261125/README.md)

!이전 설계와 중간 가채점을 없앤 파이프라인 비교 (로컬 보관 자료)

### 최종 제출 후 채점 결과

| 방식 | 기존 40문항 × 6시드 | 별도 56개 입력 × 6시드 | 호출 합계 | 토큰 합계 |
|---|---:|---:|---:|---:|
| 단독 제출 | 169/240 | 256/336 | 6 | 3,550 |
| 단일 에이전트 1회 수정 | 169/240 | 256/336 | 12 | 8,894 |
| 단일 에이전트 순차 수정 | 169/240 | 256/336 | 30 | 34,216 |
| A·B·C·D | 169/240 | 256/336 | 30 | 30,278 |

네 방식이 시드 131·157·191·223·257·293에서 얻은 점수는 순서대로 30·30·25·30·24·30점이었다. 여섯 초안은 이전 실험의 같은 시드 초안과 본문이 모두 일치했다. D는 시드마다 수정안을 선택했지만 기존 문항 240건과 별도 입력 336건의 반환값은 단독 제출과 전부 같았다. 이 재실험에서 멀티에이전트의 정확도 향상은 관찰되지 않았다. 이전 188점과의 차이에는 입력 정보와 선택 방식·호출 규칙의 변경이 함께 포함된다.

검증 시 고정 제출 24개를 원본 응답·SHA-256과 대조했고, 선택자 호출 12개 전부에 초안과 후보 3개의 코드만 후보 데이터로 들어갔음을 확인했다. 고유 모델 호출은 공통 초안·A를 공유해 48회였다. 시드 131의 독립 후보 C는 출력 상한에 도달했고 D는 A를 선택했다. 고정 제출 원문 (로컬 보관 자료) · 조건·시드별 최종 채점 (로컬 보관 자료)

### 무엇을 고정했나

- 공개 안내문만 제공하는 예약 취소 과제와 이전 비교의 동일 시드 131·157·191·223·257·293을 사용했다. 새로 뽑은 시드에서의 일반화는 이번 비교의 측정 범위 밖이다.
- 단독 제출은 첫 초안을 쓴다. 단일 1회 수정은 첫 수정안 A를 쓴다. 순차 수정과 A·B·C·D는 초안과 A를 공통으로 쓴 뒤 B·C와 선택자를 각각 호출한다. 순차 수정의 B·C는 앞선 자기 후보를 보고, 독립 제안의 B·C는 명세와 초안만 본다. 선택자는 모든 시드에서 초안·A·B·C 전문을 읽고 하나를 고른다. 선택 가능한 후보와 호출 수는 고정이다.
- 모델은 로컬 Qwen3-8B Q4_K_M이며 추론 끔, 온도 0.3, top-p 0.9, top-k 40을 사용했다. 출력 상한은 초안 1,500토큰, 각 후보 800토큰, 선택 80토큰이다. 공개 예시의 정답표, 중간 코드 실행, 점수 기반 후보 탈락·종료·재시도는 모두 제거했다.
- 모든 시드의 네 방식, 총 24개 최종 코드를 한 파일에 고정하고 각각의 SHA-256을 검증한 후 평가를 시작한다. 기존 40문항과 별도 56개 입력을 각각 채점하며 채점 결과에서 모델로 돌아가는 단계는 없다. 재개 시 확정된 제출 파일이 있으면 채점 단계만 실행한다. 고정된 설계 (로컬 보관 자료) · [실행 코드](../blind_candidates.py)

프로젝트 루트에서 `python3 -B -m experiments.monitor_cycles --blind-candidates experiments/새결과폴더`로 재현할 수 있다.
