# 예약 취소 과제 A·B·C 재실행

같은 모델·시드에서 A의 질문과 초안을 한 번 새로 생성해 B와 C에 복제했다. B는 메인이 동일한 세 관점을 순차 검토하고, C는 감시자 세 명이 같은 초안을 독립 검토한다. 두 조건 모두 검토 뒤 한 번만 수정했다. 모델 입력에는 평가용 40문항과 채점 결과를 넣지 않았다.

## 점수와 사용량

총 90번의 실제 모델 호출에서 입력·출력 90,199토큰을 사용했다. 실행 전체는 10분 7초였다. 세 모델 모두 B와 C 중 C의 총 토큰이 적었다. Qwen3에서는 C의 출력이 더 길었고 모델 응답 시간도 더 걸렸다. 점수 차이는 14B의 시드 43 한 곳에서 관찰됐다(20점에서 25점).

점수는 시드 17·29·43의 합계다. 토큰과 시간은 시드 1회당 평균이며 B·C에는 공통 초안 A를 포함한다. 모델 시간은 클라이언트가 응답을 기다린 실측 시간의 합이다.

## 질문과 답변

예약 마감 정각 포함 여부, 정정 시간과 일반 마감의 관계, 이용 시작과 정정 시간의 우선순위를 고정 답변 카드와 대조했다. 분모는 각 초안 작성 후 남은 미확인 항목을 더한 값이다. 질문 수는 정식 질문 칸에 내용이 있는 검토의 수다.

- B에서는 정식 질문 18건을 제출했고, 미확인 항목 17건 중 1건에 새 답을 받았다.
- C에서는 정식 질문 6건을 제출했고, 미확인 항목 17건 중 1건에 새 답을 받았다.

## 측정 범위

전체 실행은 607.0초였다. 여기에는 모델 로딩·교체, 담당자 답변 처리, 채점과 서버 종료가 포함된다. 조건별 모델 시간에서는 이를 제외했다. 한 모델 슬롯에서 모든 호출을 순서대로 실행했고 B·C 실행 순서를 모델·시드별로 번갈아 배정했다. 로컬 서버의 프롬프트 캐시와 기기 상태가 시간에 영향을 줄 수 있다.

모델과 생성 설정은 기존 파일럿과 같다. 질문 450, 검토 320, 코드 제출 1,500 출력 토큰 상한을 사용했다. A는 질문과 구현 2회다. B와 C는 각각 여기에 검토 3회와 수정 1회를 더했다. 이전과 정확히 같은 정식 질문에는 같은 담당자 답을 재사용했고, 새 질문은 같은 운영자 카드로 처리했다. 점수의 분모 120은 같은 40개 사례를 세 시드에서 평가한 횟수다.
