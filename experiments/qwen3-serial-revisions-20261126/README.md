# 함수 전체를 규칙표로 다시 쓰는 순차 수정 비교

처음 시도한 순차 구조다. A가 공개 명세의 요구를 해석하고, B가 조건표 전체를 작성하며, C와 D는 직전 표의 항목을 유지하거나 교체한다. 모든 시드의 제출 72개를 고정한 뒤 채점했다.

12개 시드에서 단독 초안은 기본 343/480·추가 512/672, 단일 에이전트의 5회 호출은 245/480·442/672, A·B·C·D의 5회 호출은 273/480·480/672였다. C가 B의 기본 오답 25건을 고치고 정답 12건을 잃었다. D에서는 판정이 바뀐 문항이 없었다. 시드 131에서 원래 24시간이던 일반 마감이 24초로 바뀐 사례를 계기로 기존 함수의 반환 위치만 수정하는 방법을 추가 비교했다.
