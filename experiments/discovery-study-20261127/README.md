# 감시자의 관점을 나누면 숨은 결정을 더 많이 묻는가

KUCC·YCC 학술제 5조 · 2026년 11월 27일 · 로컬 Qwen3.5-4B 작성기·검토기

**같은 모델로 같은 횟수만큼 검토해도, 호출마다 관점을 하나씩 맡기면 숨은 결정을 묻는 비율이 30%에서 79%로 올랐다.** 12개 과제 모두에서 올랐다. 대신 이 조건은 공개 설명만으로 모든 입력이 정해지는 대조 과제에서도 매번 질문했다. 담당자 회신과 코드 수정은 이 실험에 넣지 않았다.

## 1. 무엇을 비교했나

[이전 비교](../festival-validation-20261127/README.md)에서는 감시자 1명과 3명의 호출 수, 관점 배정, 호출당 질문 상한이 함께 달랐고 독립 단위가 과제·시드 6쌍이었다. 이번에는 이웃한 조건이 한 가지만 다르게 네 조건을 두고, 과제를 12개로 늘렸다.

| 조건 | 호출 | 도입 문장 | 관점 | 호출당 질문 상한 |
|---|---:|---|---|---:|
| 자체 틀 1회 (`self1`) | 1 | 방금 작성한 초안을 스스로 검토 | 세 관점을 한 문장으로 | 3 |
| 독립 틀 1회 (`ind1`) | 1 | 독립 감시자 | 세 관점을 한 문장으로 | 3 |
| 독립 3회·같은 지침 (`same3`) | 3 | 독립 감시자 | 세 호출 모두 세 관점 | 1 |
| 독립 3회·관점 분담 (`split3`) | 3 | 독립 감시자 | 호출마다 관점 하나 | 1 |

- **과제**: 숨은 결정이 2개씩 있는 작은 판정 함수 12개(정수 경계 6개, 불리언 신호 조합 6개, 유형 5개)와 대조 과제 3개. 모두 이전 실험에 쓰지 않은 소재다.
- **단위**: 과제 15개 × 시드 5개 = 75단위. 한 단위 안의 네 조건은 같은 초안을 검토한다.
- **자체 틀**은 대화를 이어받지 않는 단일 호출이다. 도입 문장과 입력 필드 하나만 독립 틀과 다르다.
- **사전 고정**: 과제·조건·판정 기준·분석 스크립트를 첫 모델 호출 전에 커밋했다(`4b935dc`, 14:29:32). 본 실행은 14:35:34에 시작해 15:07:15에 끝났다.

## 2. 결과

초안이 실패한 8단위는 규칙대로 네 조건 모두에서 뺐다. 아래는 67단위(숨은 결정 과제 53단위, 대조 과제 14단위)의 값이다. 비율은 12개 과제의 평균이고 건수는 전체 합이다.

| 조건 | 숨은 결정 발견율 | 95% 구간 | 발견 건수 /106 | 담당자에게 전달된 비율 | 단위당 검토 토큰 |
|---|---:|---:|---:|---:|---:|
| 자체 틀 1회 | 0% | 없음 | 0 | 0% | 614 |
| 독립 틀 1회 | 14% | 4~24% | 14 | 14% | 466 |
| 독립 3회·같은 지침 | 30% | 19~42% | 32 | 20% | 1,398 |
| 독립 3회·관점 분담 | 79% | 67~90% | 84 | 59% | 1,507 |

미리 정한 세 비교의 판정이다. p는 과제 12개의 차이에 대한 양측 부호 뒤집기 순열 검정이고 Holm 방식으로 보정했다.

| 비교 | 달라진 한 가지 | 발견율 차이 | 95% 구간 | 과제 오름/내림/같음 | 보정 p | 판정 |
|---|---|---:|---:|---:|---:|---|
| 자체 틀 → 독립 틀 | 도입 문장 | +14%p | +4~+24%p | 5 / 0 / 7 | 0.0625 | 확인 못 함 |
| 1회 → 3회 | 호출 수 | +17%p | +10~+23%p | 9 / 0 / 3 | 0.0078 | 차이 있음 |
| 같은 지침 → 관점 분담 | 관점 배정 | +49%p | +34~+63%p | 12 / 0 / 0 | 0.0015 | 차이 있음 |

- **이득의 대부분은 관점 분담에서 나왔다.** 호출 수와 총 질문 상한이 같은 두 조건 사이의 차이가 49%p였고, 호출만 늘린 차이는 17%p였다.
- **자체 틀은 67단위 모두에서 질문이 0개였다.** 응답은 전부 유효한 빈 배열이었다. 다만 독립 틀 1회도 5개 과제에서만 질문이 나와, 미리 정한 검정으로는 차이를 확인하지 못했다. 재표집 구간은 0을 포함하지 않지만 판정은 사전에 정한 검정을 따랐다.

## 3. 더 정확히 물었나, 더 많이 물었나

| 조건 | 질문한 단위 /53 | 질문 수 | 숨은 결정을 물은 질문 | 대조 과제에서 질문한 단위 /14 | 대조 과제 질문 수 |
|---|---:|---:|---:|---:|---:|
| 자체 틀 1회 | 0 | 0 | 없음 | 0 | 0 |
| 독립 틀 1회 | 16 | 19 | 11 (58%) | 0 | 0 |
| 독립 3회·같은 지침 | 27 | 56 | 42 (75%) | 0 | 0 |
| 독립 3회·관점 분담 | 53 | 142 | 104 (73%) | 14 | 33 |

관점 분담은 같은 지침 3회보다 질문을 2.5배 했고, 그중 숨은 결정을 물은 비율은 73%와 75%로 비슷했다. 발견율이 오른 것은 질문이 더 정확해져서가 아니라 훨씬 자주 물었기 때문이다. 이 조건은 물을 것이 없는 대조 과제 14단위 모두에서도 질문했다. 나머지 세 조건은 대조 과제에서 한 번도 묻지 않았다.

## 4. 질문 앞뒤에서 본 것

- **초안은 한 번도 보류하지 않았다.** 작성 지침은 미정인 경로를 `NotImplementedError`로 남기고 정책을 추측하지 말라고 했다. 숨은 결정 과제의 유효한 초안 53개는 숨은 결정 입력 106건 모두에서 참 또는 거짓을 반환했다. 대조 과제를 포함한 초안 67개는 공개 설명으로 정해지는 입력 349건 중 347건을 맞혔다.
- **질문 정리 단계에서 4분의 1이 빠졌다.** 관점 분담 조건이 발견한 84건 중 담당자에게 보낼 문장으로 남은 것은 62건이다. 질문이 나온 110번 중 26번은 정리 단계가 유효한 기록을 만들지 못했다(관점 분담 19번, 같은 지침 7번).
- **호출을 늘려 얻은 발견은 전달 단계에서 대부분 사라졌다.** 전달 기준으로 1회와 3회의 차이는 +6%p(구간 -7~+19%p)였다. 관점 분담의 전달 기준 차이는 +39%p(구간 +22~+55%p)였다. 전달 기준 비교는 사전에 참고용으로 정한 것이다.

## 6. 판정과 검증

- **판정**: 서로 다른 모델의 판정자 두 명이 과제 설명, [판정 기준](judge-rubric.md), 질문 문장만 보고 판정했다. 조건, 시드, 초안은 주지 않았다. 질문 271개 중 21개에서 판정이 갈렸고, 숨은 결정 과제의 판정 쌍 466개의 일치율은 93%, 카파는 0.86이었다. 위 표는 두 판정자가 모두 인정한 것만 센 값이다. 한 명만 인정한 경우를 포함하거나 판정자별로 세어도 세 비교의 p는 같았다. [질문 목록](pool.json) · [판정 A](labels-A.json) · [판정 B](labels-B.json)
- **실행기**: 이전 실험의 저장된 호출을 다시 읽혀, 자체·1명·3명 조건의 18개 검토 결과가 공개본과 같은지 모델 없이 확인했다. 18개 모두 같았다. 질문 정리 단계까지 재생하면 17개가 같고, 남은 1개는 이전 실험이 그 단위에 옛 정리기를 썼기 때문이며 같은 정리기를 쓴 보완 실행본과는 같다. [검증 결과](replay-check.json) · [검증 코드](check_replay.py)
- **이탈**: 규칙서와 다르게 한 것은 없다. 공용 모듈은 고치지 않았고 사전 고정한 16개 파일의 해시가 그대로다.
- **제외한 단위**: 초안 8개가 실패했다. 문법 오류 5개(room·retake·refund의 1129, refund·tips의 1109), 응답 길이 상한 3개(coldchain 1109, sound 1123·1129)다. 다시 뽑지 않았다.
- **검토 호출**: 관점 분담 조건의 201회 중 2회가 무효 응답이어서 질문 0개로 셌다.
- **사용량**: 고유 호출 891회, 480,686토큰, 본 실행 1,902초.
- **누가 했나**: 설계와 분석 스크립트는 Claude Code 세션에서 작성했다. 실행기 작성과 실행은 Claude Opus 에이전트가, 판정은 별개의 Claude Opus·Claude Sonnet 에이전트가 했다. 사람이 판정 표본을 다시 확인하지는 않았다.

## 7. 이 결과가 말하지 못하는 것

- 모델은 Qwen3.5-4B 하나다. 다른 모델에서도 같은지는 재지 않았다.
- 과제는 정수 하나 또는 불리언 둘을 받는 판정 함수이고 유형은 5개다. 유형 단위 검정은 가능한 가장 작은 p가 0.0625라서 판정에 쓰지 않았다. 관점 분담 비교는 유형 5개 모두에서 올랐다.
- 독립 틀 1회와 같은 지침 3회의 첫 호출은 지침과 시드가 같고 질문 상한만 다르다. 1회와 3회의 비교는 두 호출을 더한 효과와 상한 변화가 섞여 있다.
- 판정자는 둘 다 AI다.
- 질문이 답으로 이어지는지, 답이 코드에 반영되는지는 범위 밖이다. 이전 실험에서 답을 받았고 초안이 틀렸던 8건 중 고쳐진 것은 1건이었다.

## 다시 계산하기

저장소 루트에서 실행한다. 모델을 다시 부르지 않는다. 초안 실행에는 macOS 격리 실행기가 필요하다.

```sh
python3 -B experiments/discovery-study-20261127/check_replay.py   # 이전 실험 18건 재현
python3 -B experiments/discovery-study-20261127/collect.py main   # runs/ → rows.json, drafts.json, pool.json
python3 -B experiments/discovery-study-20261127/analyze.py        # → analysis.json과 요약 표
```

모델 호출 원문은 [`calls/`](calls), 조건별 검토와 질문 정리 기록은 [`runs/`](runs), 이전 과제로 한 시운전은 [`smoke/`](smoke)에 있다. [실행기](run.py) · [수집기](collect.py)
